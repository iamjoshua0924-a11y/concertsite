# PROJECT_CONTEXT

## Purpose
JPOP 연합공연(홍대 감마홀, 2027-01-30) 참가 팀 4곳의 준비 과정을 조율하는 비공개 사이트입니다. 사용자는 20명 미만이고 동시 접속은 거의 없습니다. 기능과 쓰기 편함이 최우선입니다.

## Current State (2026-10)
- v2.0: Apps Script 사이트를 Node(Express 5) + MongoDB(Atlas, GridFS) + Preact/Vite로 재구현했습니다.
- 배포 대상은 Render 무료 웹 서비스입니다(`render.yaml`).
- API 테스트 15개가 통과합니다. 모바일과 데스크톱 화면은 Playwright로 확인했습니다.

## Architecture
- 단일 Node 프로세스가 `/api/*`를 처리하고, 빌드된 SPA를 같은 출처로 서빙합니다. 그래서 CORS가 필요 없습니다.
- 클라이언트는 로그인 후 `GET /api/state` 하나로 전체 상태를 받습니다. 변경 요청 후에는 같은 엔드포인트로 다시 받습니다. 데이터가 수 KB라서 부분 갱신보다 단순하고 일관됩니다.
- 이미지와 첨부는 MongoDB GridFS(`files` 버킷)에 저장합니다. Render 무료 플랜은 디스크가 휘발성이기 때문입니다.

## Important Decisions
| 기존 결정 | 새 정보 | 변경 이유 | 새 결정 |
|---|---|---|---|
| Apps Script + 시트 DB | Render 배포 희망, 기존 MongoDB 보유 | 동시 쓰기 잠금 없음, 매 요청 16개 시트 전체 읽기, 전체 DOM 재생성으로 입력 유실 | Express + MongoDB + Preact |
| 토큰 평문 저장, 4자리 | 공개 인터넷 노출 | 무차별 대입 위험 | 10자 코드, SHA-256 해시, 로그인 rate limit, 매직 링크, 버전 기반 세션 무효화 |
| 톡방 링크·연락처를 모두에게 전송 | 라벨만 "대표자만" | UI 관례일 뿐 강제되지 않음 | 서버 `buildState`에서 역할별로 제거 |
| 투표 중복 무제한, 익명인데 팀명 노출 | 의사결정 신뢰 문제 | 집계 왜곡 | `(pollId, voterKey)` 유니크 인덱스, 재투표 = 변경, 익명은 이름·팀 모두 숨김, 서버에서 마감 검증 |
| 셋리스트 orderNo 행 단위 저장 | 순서 충돌 가능 | 동시 편집 시 번호 꼬임 | 팀 문서 안의 배열로 통째 교체 |
| UiTexts 시트로 UI 문구 109개 편집 | 새 UI는 문구 구조가 다름 | 키 매핑 불가, 유지비 큼 | 제거. 공연명, 공지, 규약, 링크 등 콘텐츠만 편집 가능하게 함 |
| 떠 있는 패널(드래그) | 콘텐츠 가림, 상태 관리 복잡 | 정보가 할 일 중심이 아님 | 홈의 "우리 팀 할 일"과 "최근 소식"으로 흡수 |
| 일정 = 자유 텍스트 | 셋리스트에 러닝타임 존재 | 시간 초과를 사람이 계산해야 함 | 시작 시각 + 팀당 배정 + 전환 시간으로 타임라인 자동 계산, 대관 종료 초과 경고 |

## Constraints
- Render 무료 플랜: 15분 무접속 시 슬립, 콜드스타트 약 1분, 고정 IP 없음(Atlas `0.0.0.0/0` 필요).
- Atlas 무료 클러스터 용량은 512MB입니다. 업로드 전에 클라이언트에서 긴 변 1800px JPEG로 압축합니다.
- 파일당 10MB, 요청당 10개.
